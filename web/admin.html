First boot — create the admin account

Log in

No admin account exists yet. The server prints a one-time setup URL on first boot — open the /setup?token=… URL from its console to create the admin account.

Log in

Login code

A 6-digit code was just mailed to the address on the account . It works once and stays valid for five minutes.

Recover your account

Enter the email address you signed up with. If it belongs to an account on this server, a mail arrives with the username and a link to set a new password.

Set a new password

You followed a recovery link. Choose a new password (min 10 chars, a digit, a non-alphanumeric); you are logged in with it right away.

Your posts

Users

Admin only: add another author to this postwisp. They log in with their own password and can write and manage their own posts, about page, media and settings.

Media library

Your uploaded photos, videos and audio. Copy a link to embed it in a post; delete removes it for good (blocked while a post still uses it).

Your account

Change the email you log in with, or set a new password. Your username stays as it is.
