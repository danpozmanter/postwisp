Features
  • One binaryServer, admin dashboard, JSON API, and public pages in a single process.
  • Single editor/editor with heading outline, styled/raw toggle, and word count.
  • Media uploadsPhoto, video, and audio with magic-byte sniffing and Range streaming.
  • Unsplash coversSearch and pick a photo as a post's header image.
  • Four-template themingPlain HTML files, re-read per request — edits go live without a restart.
  • Four languagesEnglish, German, French, and Spanish, with localized dates.
  • Light & dark themePer-visitor toggle with a site-wide default; applied pre-paint.
  • AccountsAdmin-created authors, rate-limited logins, email recovery, optional 2FA.
  • Atom feedsPer-author feeds with absolute URLs that honour X-Forwarded-Proto.
  • Append-only storageBack up by copying data/ while the server is stopped.
