Dashboard & Editor

The dashboard

The dashboard is served by the binary itself at /dashboard — a built-in page, not one of the templates (the old /admin link redirects there). Authors log in there to manage drafts, published posts, and media. Every logged-in user can also edit their own email and password from the Account button. The admin creates further author accounts; there is no open registration by design. Failed logins are rate-limited — 5 failures per username per 10 minutes (see Accounts & Security).

The editor

Every editing entry point — New Post, a post's edit link, the About page button — opens the write page at /editor, the single place a post is edited. It is one full-width writing card:

  • Formatting toolbar — headings, emphasis, code, links, lists, and quotes, fused into the card's top edge. Selecting text also opens a context toolbar with bold, italic, strikethrough, code, links, and heading 1/2/3.
  • Raw markdown toggle — flips between the styled view and the plain source.
  • Heading outline — rides beside the card on wide screens: it lists the post's headings, highlights the section you are in, and clicking an entry jumps there.
  • Status line — counts words and estimated read time, and says when edits are unsaved.
  • Save — Ctrl/Cmd-S saves.
  • Unsaved snapshot guard — leaving with unsaved edits warns before the work is lost.
  • Slug feedback — as you title a post you see the slug it will be published under.

The writing surface is styled like the published post and fills the screen.

Tip: the about page is written in this same editor — press About page on the dashboard. See Templates & Theming for how it is served.
